# Update sizes are shown as upper bounds

Steam reports only a Workshop item's total size, never how much a pending update will actually download, and an update is often far smaller than the whole item. Sizes for mods that need updating are therefore shown as "up to", as is any server total that includes an update. A mod the user isn't subscribed to downloads in full, so its size is shown as-is, and live progress replaces every estimate once a download starts. Showing the total item size as the update size was rejected because it would regularly overstate downloads by gigabytes.

Settled in the 2026-09-15 design session: Q60.
