# Unsubscribing a server's mods only removes mods no other cared-about server needs

A server's "Unsubscribe all" action removes only the mods that no other cared-about server (one the user has favourited or played before) also requires, after a confirmation showing how many mods and how much disk space that is. Unsubscribing every mod the server uses was rejected because it would silently break other servers the user plays, and the launcher already knows which mods are unique to a server.

Settled in the 2026-09-15 design session: Q38.
